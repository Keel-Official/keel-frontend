Design system

Keel Design Kit

The visual system for a read-only measurement instrument — not a marketing site. Near-black blue ink on a cool light surface, one teal accent locked to interaction, and a directional risk ramp that never borrows the accent color.

02 · Foundation

Risk ramp

A one-directional severity ramp — not a red/green traffic light. Low is a calm bluish stone, escalating through amber and burnt orange to a deep red. Each band pairs a text color with a tint, plus a 4-segment severity meter.

09 · Handoff

Using this kit

Everything is driven by CSS variables. The shipping definitions live in app/(marketing)/globals.css; the components that consume them are in components/keel/ and components/marketing/.

▹Where it applies: the marketing surface and the evidence pages. The dashboard keeps its own stylesheet (app/(dashboard)/dashboard/dashboard.css) and its own light/dark themes; the two surfaces are deliberately not wired together.
▹Three hard rules: (1) teal is for interaction only — links, focus, controls. (2) risk uses the ramp only, never teal, never a green/red traffic light, and never colour without the band word beside it. (3) recorded data is labelled wherever it appears.
▹This file is not published. It is a repository reference, opened from a checkout. It is not routed and is not served from public/.
